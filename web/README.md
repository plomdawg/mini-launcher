# Plomcase

A lightweight web app for designing and exporting wraparound game-case art. It has no package dependencies or build step (the 3D preview uses a vendored copy of three.js); the included Python standard-library server serves the app and proxies SteamGridDB and LaunchBox Games DB requests to avoid browser CORS restrictions. Projects and artwork are stored in the browser's IndexedDB. Use **Export JSON** to move an editable project to another browser, or **Export all** in the library panel to back up every saved case to one `plomcase-library-<date>.json` file (**Import** adds a backup or a single project file back into a library; re-importing a backup updates cases instead of duplicating them); **Download SVG** and **Export print PNG** create artwork files.

Run locally with Python 3.10 or newer:

```sh
python server.py
```

The server listens on all interfaces at port 8787 by default (set `PLOMCASE_HOST=127.0.0.1` to keep it local-only, `PORT` to change the port). Then open <http://127.0.0.1:8787>. Opening `index.html` directly still allows local artwork editing, but the SteamGridDB and LaunchBox pickers need the server.

## Prototype features

- Back, spine, and front cover in one spread. Face width, face height, and spine width are separate settings (standard DVD insert 129.5 × 183 × 14 mm by default, which fits under a DVD case sleeve or on a DVD-sized printed case; a **Case size** preset also offers the legacy 80 × 120 × 13 mm 2:3 mini case). A note under the size fields shows how much a 2:3 grid loses or leaves over on the current face.
- Drag and drop or browse for separate cover art, including 600 × 900 SteamGridDB images. The project name is printed vertically on the spine, with an optional rotated logo near its lower end. An optional **title logo** (e.g. a stylized wordmark or clear logo) replaces the printed project name: it is laid along the spine in the spine direction, fit to the spine width, and kept clear of the lower logo, which still shows. **Spine logo size** and **Title logo size** sliders (40–100%) shrink either logo when it fills the spine too tightly.
- Optional spine art upload for using a scan of the original spine: it replaces the spine title, title logo, and logo. Choose stretch (default) or fill to cover the whole spine, or fit to show the whole image with the spine fill around it; landscape images are rotated to match the spine direction.
- Optional disc art for a round disc label: upload square art laid out like a full 120 mm CD, choose fill or fit, and set the printed diameter (50 mm default) and center hole (6.25 mm default). The art is scaled to the printed diameter and clipped to the disc; the center hole and the area outside the circle stay transparent. A small disc preview sits under the wrap preview, with **Download disc SVG** and **Export disc PNG** (selected DPI, bleed ring, and cut circles when cut guides are on).
- LaunchBox Games DB picker (the preferred source) for region box fronts, backs, spines, discs, square art, and clear logos (no key needed); a clear logo can be applied as the spine logo or the spine title logo. The disc section's **Find disc art on LaunchBox** button lists Disc and Square images first and applies them to the disc label; Square art covers cart-only games with no disc scans.
- Embedded SteamGridDB picker for cover grids and logos. Search is manual; grid results can be limited to 600 × 900 and are paged in batches of up to 50.
- **Platform & rating** overlays for when the cover art (e.g. a SteamGridDB grid) doesn't show where a game is from: pick a platform (Steam, PlayStation 1–5, PSP, Vita, Switch/Switch 2, Wii/Wii U, GameCube, N64, SNES, NES, Game Boy family, DS/3DS, Xbox family, Dreamcast, Genesis, Saturn) and show its logo as a full-width **top banner** in the platform's color or a **corner badge**, plus an optional badge at the top of the spine (the title shrinks to make room). An **ESRB rating** badge (EC, E, E10+, T, M, AO, RP) can sit in any front corner, optionally repeated on the back. Platform and rating are saved per case; style, size and corners are shared settings with **Save as default**. Picking a game from a LaunchBox search pre-selects its platform when none is set. The logos are bundled SVG/PNG files in `overlays/` (catalogs: `platforms.json`, `ratings.json`; add an entry plus its file to offer more; `ink` tints a logo to one color) and are embedded into exports as data URIs.
- Three cover-art fits: **Fill panel** (default; crops the overflow, with a top/center/bottom crop position so a top logo survives), **Fit + blurred extension** (the whole image, with a blurred, darkened, zoomed copy of itself filling the leftover space), and **Fit whole image** (plain dark bars).
- Editable case face size, spine width (14 mm default), title size (8 mm default), bleed (0 mm default), cut guides (off by default), typeface, spine direction, and spine/text colors. Spine fills can use a seamless blur of the covers (each cover's displayed edge is mirrored into the spine, crossfaded back → front, blurred, and feathered a few mm onto both covers; plain or darkened), sampled back/front cover-edge colors in either gradient direction, dark/light blends, edge solids, a mixed color, or a custom solid; an adaptive title keyline helps keep text readable. Title size auto-fits to the spine width and length. Rubik Bold and Impact are available.
- Shared settings defaults are stored in this browser. Each project follows those defaults until you edit a setting; edited settings become project overrides. Use **Save as default** or **Use default** within a section to manage that section independently. Project values and override markers are included in exported project JSON; another browser will apply its own shared defaults to inherited settings.
- SVG or DPI-selected PNG export. The PNG includes bleed, selected-DPI pixel dimensions, and physical-resolution metadata for the entered millimeter dimensions.
- Local project library plus portable `.plomcase.json` project files and whole-library JSON backups (**Export all** / **Import**).
- **3D case** preview (toggle next to the export buttons): the current wrap is mapped onto a game case sized from face height × face width × spine width, with a hinged front lid (Open/Close button or 0–150° slider) and a disc on the tray hub sized from the disc diameter, with the disc art on top when available. The disc is shown at real scale; opening the lid eases the camera in toward it until you orbit or zoom yourself (**Reset view** restores that). Drag to orbit, scroll to zoom. It re-renders about 250 ms after each edit and pauses while the 2D layout is shown. Needs WebGL; three.js is vendored under `vendor/three/` (see its README for the pinned version) and only loaded the first time the 3D view is opened. Like the PNG export, the texture is rasterized from the SVG, so Google Fonts may fall back to a local font in the 3D view.

## Notes

This is an early layout prototype. Confirm the case's measured print dimensions and test a paper proof before printing finished inserts. The app does not send images to a service. Rubik is fetched from Google Fonts when online; Impact uses a locally installed font.

The case art provided separately by the user is deliberately not bundled into this source folder, so the public source can stay free of third-party cover artwork.

## SteamGridDB picker

The picker uses SteamGridDB's v2 API. Each user supplies their own API key. Plomcase relays requests through its same-origin server to avoid CORS; the server does not store or log the key. If **Remember on this device** is selected, the key is stored in this browser's local storage; clear it by unchecking that option and searching, or by clearing this site's browser storage. The API documentation caps each result page at 50 items; it does not publish a numeric request quota. The picker only searches when asked and does not poll.

The proxy only forwards SteamGridDB game-search, grid, logo, and approved artwork-download requests. For remote deployment, use HTTPS and put the service behind your normal authentication proxy; the API key passes through the Plomcase server to SteamGridDB. An API key can be generated from the [SteamGridDB API preferences page](https://www.steamgriddb.com/profile/preferences/api).

## LaunchBox Games DB picker

**Choose art from LaunchBox** opens a picker backed by the community [LaunchBox Games Database](https://gamesdb.launchbox-app.com/). No account or API key is needed. Search by title (one result per platform), or paste a game link such as `https://gamesdb.launchbox-app.com/games/details/1992-…` or just the numeric game ID. Images are grouped by type (Box - Front, Box - Back, Box - Spine, Disc, Square, Clear Logo) with their region and pixel size; pick an **Apply to** target or leave it on *Match image type* (Square maps to the disc label). Once a game is open, **View on LaunchBox Games DB ↗** links to its page on the site.

Requests happen only when you search, open a game, or apply an image; nothing is cached, polled, or stored on the server. The server reads only the public game images/details pages and search results on `gamesdb.launchbox-app.com`, and only downloads `https://images.launchbox-app.com/<id>.jpg|png` files (40 MB cap; like the SteamGridDB proxy, only JPEG, PNG and WebP responses are passed through). Preview thumbnails load directly from the LaunchBox image host in your browser. The parser reads the site's HTML, so a LaunchBox redesign can break it; run `python -m unittest discover -s web/tests` after changes. To offer more image types, add them to `LAUNCHBOX_IMAGE_TYPES` in `server.py`.

Artwork on LaunchBox is contributed by its community and belongs to its respective owners; use it for personal prints only.
